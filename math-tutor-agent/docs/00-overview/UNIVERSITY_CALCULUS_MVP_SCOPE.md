# 大学高等数学 MVP 范围收敛

最后更新：2026-10-31

## 1. 产品边界

首个可交付版本只服务大学生的高等数学学习，不再向用户提供学科、学段或具体年级选择。

固定业务范围如下：

| 维度 | 固定值 | 展示名称 |
| --- | --- | --- |
| 学科 | `math` | 数学 |
| 学段 | `university` | 大学 |
| 产品范围 | `math + university` | 大学高等数学 |
| 默认知识目录 | `UC.C1` | 函数、极限与连续 |

第一版内容按现有七章大学高数目录逐步建设。已经完成的第一章知识点、知识正文、题型和先修关系作为首批可用内容。

## 2. 用户流程变化

- 注册学生账号时不再填写学段。
- 新建辅导会话时不再提交 `subject` 或 `grade`。
- 新手引导不再询问年级，只询问希望优先学习的高数方向。
- 知识星球不再携带学段筛选参数，只能浏览大学高数目录。
- 管理台不能创建小学、初中或高中目录、知识点和数学方法。
- 题目生成任务只接受 `subject=math`、`grade_band=university`。

## 3. 数据字段处理

### 3.1 已删除

| 位置 | 字段 | 原因 |
| --- | --- | --- |
| `student_profiles` | `current_grade` | 只表达 1—12 年级，对大学高数没有稳定含义 |
| 注册请求 | `grade_band` | 用户不需要选择，服务端固定为 `university` |
| 认证响应 | `grade_band` | 前端不再依赖用户学段，避免把固定范围伪装成个人配置 |
| 创建会话请求 | `subject`、`grade` | 产品范围固定，客户端输入会造成越界和数据不一致 |
| 学生端和管理端表单 | 学段选择控件 | 已经没有可选项 |

### 3.2 保留为内部字段

`subject` 和 `grade_band` 继续保留在目录、知识点、题库、会话、索引和审计数据中。它们不再是用户选择项，而是固定的内部范围标识。保留它们有四个用途：

1. 让 MySQL、Qdrant、Redis 缓存键和审计记录使用同一范围标识；
2. 避免破坏现有题库与索引结构；
3. 隔离以前录入的其他学段内容，使其不会进入当前产品；
4. 将来若验证了新产品线，可以通过新版本迁移扩展，而不需要重新设计所有数据对象。

大学阶段不使用中小学的精确年级，因此 `grade_codes` 在 `grade_band=university` 时允许为空。知识点编码、课程目录和题型标签负责表达更精确的学习范围。

## 4. 数据迁移

当前结构基线固化以下规则：

1. 将学生资料的 `grade_band` 统一为 `university`；
2. 将现有学习会话统一为 `subject=math`、`grade_band=university`；
3. 删除 `student_profiles.current_grade`；
4. 将数学思想与方法的适用学段统一为大学；
5. 给学生资料和学习会话增加数据库范围约束。

旧的非大学知识目录、知识点和题库内容不会由本次迁移物理删除。学生接口和管理端查询会过滤它们，便于后续审计、归档或人工清理。

## 5. 题库与生成边界

题库生产仍采用“可信母题 → 候选变式 → 条件检查 → 独立解题 → 工具证据 → 去重与泄漏检查 → 独立复核 → 规则准入”的离线流程。

本次范围收敛不代表大学高数题可以直接自动批准。现有 `quadratic-v1` 是早期一元二次方程验证基线，不能作为大学高数生产准入依据。大学高数题型只有在对应的确定性验证器、评估集和错误准入阻断指标完成后，才允许进入 `approved` 和 `indexed`。

运行时“做一道相似题”只允许从大学高数知识点中已发布、已审核的题型内容生成。系统先抽取母题 `MPR-Core`，再生成候选并由隔离复核器重新抽取候选 MPR、建立 `MPR-Relation`。S/M 只表示两题关系；生成器自报等级不参与准入，`UNKNOWN` 或 `review_required` 会阻止创建练习会话。

通过 MPR 会话级质量门的题仍然是 `session_only` 临时题。当前 `independent_llm_review` 不能替代大学高数题型的 SymPy、数值抽样或其他确定性工具证据，因此不会自动进入正式题库或生产索引。旧的线性方程和一元二次方程确定性快捷生成路径不再作为学生入口。

## 6. RAG 与学习记录

- 教材知识检索固定使用 `subject=math`、`grade_band=university`。
- 大学阶段不再使用精确年级过滤，避免空 `grade_codes` 导致合法内容无法召回。
- 学生个人历史检索沿用相同范围，但继续与教材知识数据隔离。
- 新学习记录显示为“数学 / 大学”，并通过知识点编码记录具体章节和能力证据。

## 7. 暂不进入 MVP

- 小学、初中和高中数学内容入口；
- 学段切换及跨学段推荐；
- 1—12 年级资料与年级筛选；
- 未完成确定性验证的大学高数题自动准入；
- 从任意学生题目直接生成并发布正式题库内容。

家长授权、数据导出和账号能力暂时保留为平台能力，不参与数学内容范围判断，也不阻塞大学高数 MVP 的交付。
