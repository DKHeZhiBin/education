# RAG 首批知识来源与许可策略

## 1. 结论

首批来源采用“国内课标做结构、开放教材做内容”的组合：

- 教育部数学课程标准只登记版本、官方链接和人工整理的知识点映射，暂不复制全文；
- 教材正文、例题和公开题解优先采用允许商业使用与改编的 CC BY、CC BY-SA 内容；
- 只有来源、版本、许可、内容校验和及审核记录齐全的材料才能进入生产索引；
- 教师专属答案、许可不明网页、非商业内容和现有评估集默认禁止导入。

机器可读登记表位于 `rag/sources/source_registry_v1.json`。登记表是导入允许清单；未出现在允许清单中的来源按 `blocked_until_reviewed` 处理。

## 2. 第一批允许清单

| 来源 | 用途 | 许可 | 当前决定 |
| --- | --- | --- | --- |
| 教育部《义务教育数学课程标准（2022年版）》 | 小学、初中知识体系和版本依据 | 未确认开放内容许可 | 只登记元数据和人工知识点映射 |
| 教育部《普通高中数学课程标准（2017年版2020年修订）》 | 高中知识体系和版本依据 | 未确认开放内容许可 | 只登记元数据和人工知识点映射 |
| ORCCA | 基础与中级代数、例题、公开练习和检查点解答 | CC BY 4.0 | 可作为生产内容候选 |
| Active Prelude to Calculus | 函数、三角、指数对数和微积分预备 | CC BY-SA 4.0 | 可作为生产内容候选 |
| Active Calculus Single Variable 2e | 极限、导数、积分、应用题和公开答案 | CC BY-SA 4.0 | 可作为生产内容候选 |
| Advanced High School Statistics | 高中统计、概率、公开例题 | CC BY-SA 3.0，存在文件级例外 | 完成文件审计后可入库 |
| Discrete Mathematics: An Open Introduction 3e | 逻辑、证明、组合、数列和入门数论 | CC BY-SA 4.0 | 只固定第三版后可入库 |

## 3. 质量依据

首批正文来源至少满足以下一项，且必须同时具有明确许可：

1. 由高校或社区学院数学教师团队编写并长期用于正式课程；
2. 具有公开的勘误或反馈渠道；
3. 由 AIM Open Textbook Initiative 按数学正确性、课程覆盖、练习数量、编辑质量和课堂采用情况进行评审；
4. 题目、示例或题解经过作者团队或课程教师维护。

AIM 的评审用于判断教材质量，不代替许可判断。每份内容仍以自身许可证和文件内版权标记为准。

## 4. 课程标准的使用边界

教育部官方页面确认了两个现行数学课程标准的发布机构、名称和版本。当前没有在这些页面确认到允许商业复制、改编和生成式产品全文入库的开放许可，因此首批只保存：

- 标题、发布机构、版本代码和官方 URL；
- 课标适用学段；
- 团队依据课标人工编写的知识点代码和映射关系；
- 指向官方文档章节或页码的短定位。

不得把官方 PDF 批量切片、生成向量或重新分发。若以后取得书面授权或完成明确的权利审查，再把对应来源状态升级，并保留授权文件编号。

## 5. 例题与题解入库规则

开放教材不代表其所有附件均可导入。每道题和题解执行以下规则：

1. 题目、提示、答案和完整题解分别记录来源定位；
2. 只有许可证覆盖的公开正文可以导入；
3. 只有最终答案的材料保存为 `final_answer`，不能包装成完整题解；
4. `solution_text` 只保存公开的分步解答，或本项目独立编写并完成审核的题解；
5. 教师登录后才能查看的 solution manual、考试题库和答案指南不导入；
6. 本地翻译、重写和重新编排属于派生内容时，记录原文、修改说明和相同方式共享义务；
7. 插图、照片、数据集和外部互动练习逐项检查，不能沿用教材正文许可证进行推断；
8. 导入后初始状态为 `unreviewed`，数学教师确认题干、答案和解法后才变为 `approved`；
9. 题解的 `verification_status` 独立记录，审核通过不自动等于程序化完全验证。

## 6. 许可履约字段

导入程序必须为每个 `SourceReference` 保存：

- 官方标题、作者/机构和权威 URL；
- 精确许可证名称与许可证 URL；
- 获取日期、版本或 Git commit；
- 原始文件 SHA-256 和规范化来源 fingerprint；
- 允许范围、排除范围和第三方材料说明；
- 标准署名文本；
- 是否要求 ShareAlike；
- 文件级许可审计结果。

面向学生展示引用时至少包含标题、作者或机构、版本、原文定位和链接。使用 CC BY-SA 内容生成可构成派生的教学材料时，输出或相应内容页面还要展示适用许可证和修改说明。

## 7. 明确禁止导入

### OpenStax

OpenStax 当前许可说明将教材置于非商业许可下；具体数学教材页面还明确要求，将内容用于大型语言模型或生成式 AI 产品前取得书面许可。因此在取得许可前，不进入本产品 RAG。

### MathOdyssey

MathOdyssey 已作为冻结评估集使用，且上游限制训练用途。将题目或解答加入 RAG 会造成评估泄漏，因此保持 `evaluation_only`。

### 教师专属材料与普通网页

登录后可见的教师答案、考试题库、论坛帖子、个人整理文档以及只有“免费下载”说明的网页均不进入来源允许清单。免费访问不等于允许复制、改编或用于生成式产品。

## 8. 首批覆盖与缺口

| 范围 | 第一批来源 | 状态 |
| --- | --- | --- |
| 国内小学至高中知识点结构 | 教育部课程标准 | 可做人工分类映射，不做全文 RAG |
| 基础和中级代数 | ORCCA | 可入库 |
| 函数、三角和微积分预备 | Active Prelude | 可入库 |
| 单变量微积分 | Active Calculus 2e | 可入库 |
| 高中统计与概率 | Advanced High School Statistics | 文件审计后入库 |
| 逻辑、证明、组合、数列、入门数论 | Discrete Mathematics 3e | 可入库 |
| 中国教材原文 | 尚无已授权来源 | 缺口 |
| 中学欧氏几何系统教材 | 尚未选定与国内范围匹配的来源 | 缺口 |
| 中文高难竞赛题及完整题解 | 尚无可用于生产 RAG 的授权库 | 缺口，优先自建并人工审核 |

高难题评估集继续保持独立。生产用中文高难题建议由项目自行命题或取得作者明确授权，再进行双人审核和题解验证。

## 9. 首次导入顺序

1. 把允许清单条目写入 `source_references`；
2. 为两个国内课标建立 `curriculum_versions`，只保存元数据；
3. 下载开放教材的固定版本，保存原始文件、许可证和 SHA-256；
4. 排除封面、商标、第三方图片、外部互动内容和教师专属附件；
5. 建立 `knowledge_documents`，完成清洗和切片；
6. 抽取公开题目、答案和题解，保留精确 locator；
7. 完成人工审核后再建立关键词和向量索引；
8. 使用引用检查和泄漏检查通过后，才允许 Provider 在生产环境召回。

## 10. 复核频率

- 每次导入新版本前重新检查许可证页面；
- 每季度检查允许清单中的 URL、许可证和最新版变化；
- 许可证从允许商业使用变为非商业或新增 AI 限制时，暂停新导入并冻结对应索引版本；
- 已经合法取得的固定版本是否可以继续使用，依据保存的许可证快照和具体条款单独判断，不能直接套用新版结论。
