# 家长报告证据与样本范围

## 数据准入

家长报告只读取同时满足以下条件的数据：

1. 学习会话属于目标学生；
2. 会话状态为 `completed`；
3. 会话已经在 MySQL 中写入结构化 `learning_record`。

进行中的会话、只有聊天消息但没有学习记录的会话、演示数据、题库统计、其他学生记录和模型推测均不进入报告。

## 样本范围

接口通过 `sample_scope` 明确返回：

- `status`：存在样本或无样本；
- `scope_type`：当前为全部已完成记录；
- 完成记录数和知识点证据数；
- 第一条、最后一条记录日期；
- 覆盖学科和年级；
- 报告生成时间。

少于三条完成记录时，报告明确提示样本不足以支持长期能力推断。无样本时所有计数为零、日期为空，不填充演示数字。

## 知识点汇总

每个知识点只聚合结构化 `LearningRecordKnowledge` 对应的领域记录，展示：

- 证据条数；
- 记录到错误的次数；
- 有效尝试次数；
- 实际使用过的最高提示等级；
- 已掌握证据条数；
- 最近一次掌握状态及日期。

前端不再把知识点顺序转换成虚构的掌握百分比。

## 建议生成

只有存在错误证据或最近状态不是“已掌握”的知识点才会生成建议。建议文字同时显示支撑它的证据条数、错误次数和最近状态。没有符合条件的证据时返回空建议列表。

家长或管理员仍须经过既有的学生关联授权检查；学生只能查看自己的报告。
