# 四层重复检测

## 目标

`FourLayerDuplicateDetector` 在候选题进入自动准入门前，从题干、公式、结构化条件和解法步骤四个层面比较同题型内容。检测结果写入阻断型 `duplicate_detection` 证据。

检测器用于拦截以下内容：

- 只调整空格、标点、全半角或排版的重复题；
- 只替换变量名或交换等式两边的重复公式；
- 公式、定义域、目标和答案类型相同，仅改写自然语言的题目；
- 多层结构都高度相似、没有形成有效变化的伪变式。

正常的参数变化、条件变化或难度变化可以保留。解法模板相同本身不会被判定为重复。

## 输入范围

Repository 只接受：

- 处于 `candidate`、`validating` 或 `revision_required` 的生成题；
- 具有结构化条件和求解目标的题目；
- 来自隔离解题 Agent 且有最新 `solution_independence` 证据的结构化题解；
- 启用的 `four_layer_duplicate` VerifierVersion。

比较池包含相同学科、相同题型且没有退役的题目，包括可信母题、同批候选题和已经批准或索引的题目。第一版单次最多读取 2000 道；超过上限时证据为 `inconclusive`，不能以不完整扫描结果证明唯一性。

评估集不在本比较池中。与隔离评估集的相似度检查属于独立的 `evaluation_leakage_detection` 流程。

## 第一层：文本

文本层执行 Unicode NFKC、大小写、空白和标点规范化，再生成字符三元组特征：

- 规范文本完全一致且公式 AST 也相同时判定确定重复；
- 字符三元组使用 Jaccard 相似度；
- 数字保留，因此正常参数变式不会因模板文字相同直接成为文本完全重复。

## 第二层：公式 AST

公式层读取显式和隐含条件中的规范方程或不等式，使用 Python AST 白名单构建规范结构：

- 变量按出现顺序改名为 `v0`、`v1`；
- 数字使用规范 Decimal 表示；
- 加法和乘法子节点排序；
- 等式两边排序；
- 支持基础四则运算、整数幂和 `sqrt`；
- 不使用 Python `eval`，也不把原始公式当代码执行。

因此 `x^2-5x+6=0`、`0=y^2-5y+6` 和仅调整加法顺序的表示会得到同一个公式指纹。

## 第三层：条件结构

条件层比较：

- 显式或隐含条件；
- 条件类型；
- 规范公式；
- 非公式条件的规范文本；
- 相关符号；
- 求解动作、目标对象、答案类型和目标约束。

条件文本、目标对象和约束中的变量名会统一映射为 `v0`、`v1`。隐含条件的推断依据会保留在指纹中，置信度数值不参与重复判定。

## 第四层：解法结构

解法层不依赖大段题解文字，而是比较：

- 解法名称；
- 步骤顺序；
- 每步动作和规范结果；
- 步骤依赖关系；
- 依据类型；
- 关联知识点。

候选题必须提供结构化独立题解。比较题缺少题解时，该比较项的解法层标记为不可用，其他三层仍正常执行。

## 判定规则

### 确定重复

满足任一规则：

1. 题目内容哈希完全相同；
2. 规范化题干和公式 AST 同时完全相同；
3. 公式 AST 和条件目标结构同时完全相同。

单独出现相同的通用题干，例如“解下列方程”，不会覆盖公式差异而误判为重复。

### 近重复

必须同时满足：

- 四层可用项加权相似度不低于 `0.94`；
- 文本相似度不低于 `0.92`；
- 公式相似度不低于 `0.90`；
- 条件相似度不低于 `0.90`。

默认权重为文本 `0.30`、公式 `0.30`、条件 `0.25`、解法 `0.15`。解法相同只增加联合分数，不能单独阻断题目。

## 证据状态

| 状态 | 条件 | 准入效果 |
|---|---|---|
| `passed` | 完整比较池中未发现确定重复或近重复 | 满足重复检测门槛 |
| `failed` | 至少发现一个确定重复或近重复 | 阻断自动准入 |
| `inconclusive` | 比较池截断，或候选公式、条件、解法无法形成必要签名 | 阻断自动准入 |

证据保存命中题目、与母题或同批题目的关系、四层指纹、每层分数、联合分数、判定原因、规则门槛和验证器版本。

## 并发与幂等

加载阶段记录候选题、独立题解、全部比较快照和比较池总数。保存阶段重新锁定候选题和题解，并重新构造比较池。候选内容、题解、状态版本或比较池发生变化时拒绝写入旧结果。

证据 Payload 使用规范 JSON 计算 SHA-256，并包含 VerifierVersion，重复执行相同版本和输入时返回已有证据。

## 调用顺序

```python
repository = DuplicateDetectionRepository()
loaded = repository.load_detector_context(
    session,
    problem_id=problem_id,
    solution_id=solution_id,
    verifier_version_id=verifier_version_id,
)

report = FourLayerDuplicateDetector().detect(loaded.detection_context)
evidence = repository.persist_report(session, context=loaded, report=report)
session.commit()
```

检测器只追加证据，不直接修改内容状态。后续规则准入门依据最新阻断证据决定进入修订、隔离或批准。
